# FINGER SLASH

カメラとAIで遊ぶアクションゲームです。カメラ映像はブラウザー内で処理し、録画・送信しません。

## 開発

Node.js をインストールしてから、プロジェクトのフォルダーで実行します。

```sh
npm install
npm run dev
```

本番用ファイルは次のコマンドで `dist/` に作成されます。

```sh
npm run build
npm run preview
npm test
```

Netlify Drop などへ公開するときは、`dist/` の中身をアップロードしてください。カメラを使う場合は HTTPS で開きます。

## ファイル構成

- `index.html` はアプリの起動に必要な最小のHTMLです。
- `src/main.js` はスタイルと画面テンプレートを読み込み、ゲームを起動します。
- `src/config.js` はゲームの調整値を管理し、`src/game/` はモンスター・火の玉攻撃・スコア計算を管理します。
- `src/input/` はカメラとモーション検出、`src/audio/` は効果音とBGMを管理します。
- `src/game/runtime.js` はゲーム進行と画面表示をまとめています。
- `src/view.html` と `src/styles.css` は画面テンプレートとスタイルです。
- `src/game/boss.js` はボス（スライムキング）の移動・火の玉の発射タイミング・体力を管理します。
- `src/game/ghost.js` は前のプレイヤーの記録の保存・補間を担当します。
- `src/game/gesture.js` は手の形（グー・パー）の判定と、こぶしゲージ・盾の状態を管理します。
- `src/game/two.js` は2人同時プレイの左右の手の割り当て・勝敗・2人用ランキングの保存形式を管理します。
- `assets/` に背景透過の `slime.png`、`ghost.png`、`bat.png`、`golem.png`、`star.png`、`bomb.png`、`fireball.png`、`boss.png` を置くと、対応する絵に差し替わります。

## ボス戦

プレイ時間が30秒なら残り5秒、60秒なら残り15秒になるとスライムキングが登場します（体力は30秒版150・60秒版300）。最初は画面の上のほうを左右にゆっくり往復し、残りHPが66%以下になると上下にジグザグしながら速く動き、33%以下になるとさらに高く上下して高速で動きます。出現から3秒後・その後3秒ごとに火の玉を投げます（投げる0.6秒前に光って「！」を出します）。HPが66%以下で2方向、33%以下で終盤の連続攻撃として最大まで分散した火の玉を投げます。同時に2発を超える火の玉は投げません。

通常の斬り（220px/秒以上）は0.12秒おきに10点ぶんのダメージ、火の玉を斬ってはじき返すと、動いているボスへ向かって飛び（どこではじいても約0.4秒で届きます）、当たると30点ぶんのダメージになります。体力を削りきると「ボスをたおした！」で500点（コンボ倍率なし）が入り、ボス・火の玉が消えます。倒せなかった場合は結果画面に「ボスのHP 残り◯%」が表示されます（切り上げ。1%未満でも0%にはなりません）。

ボスがいる間、通常モンスターは最大6体、通常の火の玉攻撃は出ません（ボス自身の火の玉だけが出ます）。「てきの攻撃」をオフ（`?attack=0`）にしているときは、ボスも火の玉を投げません（斬りとグーでだけダメージを与えます）。スタッフメニューでオン・オフでき、URLに `?boss=0` を付けても無効にできます（既定はオン）。

## ゴーストレース

プレイ中は、斬りに使っている点（指先。マウスはカーソル）の座標（0〜1に正規化）と得点を0.1秒ごとに記録し、時間切れで終わったときだけ30秒用・60秒用それぞれ別の記録として保存します（途中でメニューに戻ったときや、手が一度も映らなかったときは保存しません）。次のプレイヤーには、同じ時間モードの前の記録を水色の残像と「前の人 ◯点／いま ◯点」の比較バーで表示し、結果画面に「前の人をこえた！」などの文言を出します。保存するのは座標と得点だけで、名前・顔・映像は保存しません。「今日の記録をリセット」で両方の記録が消えます。スタッフメニューまたは `?ghost=0` で無効にできます（既定はオン、既存の記録は消えません）。

## 手の技（グー・パー）

指（人さし指・中指・薬指・小指）が3本以上曲がっていると「グー」、4本とも伸びていると「パー」と判定します。こぶしゲージは、通常の敵を1体たおすごとに10%、ボスへ斬りダメージが1回入るごとに2%たまり、100%の状態でグーを0.5秒続けると発動して、画面の通常モンスターを全滅・ボスに30ダメージ・飛んでいる火の玉をすべて消します（発動後、ゲージは0に戻ります）。パーを0.3秒続けると2秒間、手のひらに追従する盾が出て、触れた火の玉を消します（再使用まで8秒）。グーの形を作っている間は、その手の斬り判定の位置が更新されません（誤って斬らないため）。

マウス操作のときは、右クリック長押しがグー、Shiftキー長押しがパーの代わりになります（右クリックのメニューは出ません）。スタッフメニューまたは `?gesture=0` で、ゲージ・判定・表示・マウスの代わりをすべて無効にできます（既定はオン）。

## 2人同時プレイ

メニューの「人数」で「2人」を選ぶと、画面の左右に1人ずつ立って同時に遊べます。AIハンドのときだけ選べます（モーション・マウスのときは「2人」が押せず、「AIハンドのときだけ選べます」と表示されます。AIハンド以外に切りかえると自動で1人に戻ります）。スタート時にAIを読みこめなかった・スキップしたときは、そのプレイだけ1人（モーション）で遊び、メニューに戻ると「2人」の設定のままに戻ります。2人で遊んでいる途中にAIが止まった（エラーが続いた・重すぎた）ときは、モーションでは左右の人を見分けられないため、そこまでの点数で2人の結果を出して終わります（この回はランキングに残しません）。カウントダウン中なら1人用で数えなおし、次の回からはメニューに戻るまで1人（モーション）で遊びます。2人のときはプレイ時間が60秒に固定され、TIMEは選べません。URLオプションはありません。

- **左右の割り当て**: AIには最大4つの手を探させ、手のひらの中心が画面の左半分にある手を「左の人」、右半分にある手を「右の人」にします。ブース表示では小さく写った手（うしろに並んでいる人の手）は使わず、画面の真ん中の細い帯（不感帯）にある手はどちらにも割り当てません。各側でいちばん大きく写っている手を1つだけ使います。プレイ中は真ん中に点線で境目を表示します。
- **点数**: 敵とボスは2人で共有します。敵を斬った人が点数とこぶしゲージを得ます。ボスはどちらの斬り・はね返し・グーでもダメージを受け、撃破の500点は最後にダメージを与えた人に入ります。はね返した火の玉の点数とコンボは、はね返した人のものです。
- **ペナルティ**: 火の玉が届いたときにコンボが切れるのは、届いた位置の側（左半分か右半分か）の人です。ばくだんは斬った人のコンボが切れ、点が減ります。残り時間は2人共通なので、どちらのペナルティでも減ります。
- **手の技**: グー・パーは、それぞれ自分の側の手だけで判定し、ゲージも盾も1人ずつ別です。
- **表示**: 左上に「左の人」、右上に「右の人」の点数とコンボを出します。ゴーストレースは使いません。
- **結果画面**: 「左の人 ◯点」「右の人 ◯点」を並べ、多いほうに「勝ち！」、同点なら「ひきわけ！」を出します。ボスが残っていれば「ボスのHP 残り◯%」も出します。名前の入力はありません。
- **ランキング**: 1人用（30秒・60秒）とは別に、2人用のボード（保存キー `scoresTwo`）に2人の合計点で記録します。1件は `{ total, l, r, ts }` の形で、表示の名前の欄は「左◯／右◯」になります。「人数」で2人を選んでいる間はこのボードを表示します。「今日の記録をリセット」で今日の2人用の記録も消えます（ほかの日のベストは残ります）。

調整値は `src/config.js` の `TUNING.two` にあります。

- `duration`（60）: 2人プレイのプレイ時間（秒）
- `maxHands`（4）: 2人プレイのときにAIに探させる手の数（1人プレイは3）。1人⇔2人を切りかえると、次のスタート時にAIを作り直します
- `centerDeadZone`（0.04）: 画面の真ん中で、左右どちらにも割り当てない帯の幅（画面の幅に対する割合）

## URL オプション

- `?booth=1` ブース表示
- `?mode=ai`、`?mode=motion`、`?mode=mouse` 操作モード
- `?diff=easy`、`?diff=normal`、`?diff=hard` 難易度
- `?time=30` または `?time=60` プレイ時間（それ以外の値は無視され、既定は30秒）
- `?view=show`、`?view=blur`、`?view=hide` カメラ映像の表示方法
- `?mute=1` 消音、`?assets=0` 画像を無効化、`?attack=0` 火の玉攻撃を無効化
- `?boss=0` ボス戦を無効化
- `?ghost=0` ゴーストレースを無効化
- `?gesture=0` 手の技（グー・パー）を無効化
