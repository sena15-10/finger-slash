# FINGER SLASH

カメラとAIで遊ぶアクションゲームです。カメラ映像はブラウザー内で処理し、録画・送信しません。

## 開発

Node.js をインストールしてから、プロジェクトのフォルダーで実行します。

```sh
npm install
npm run dev
```

本番用ファイルは次のコマンドで `dist/` に作成されます。

```sh
npm run build
npm run preview
npm test
```

Netlify Drop などへ公開するときは、`dist/` の中身をアップロードしてください。カメラを使う場合は HTTPS で開きます。

## ファイル構成

- `index.html` はアプリの起動に必要な最小のHTMLです。
- `src/main.js` はスタイルと画面テンプレートを読み込み、ゲームを起動します。
- `src/config.js` はゲームの調整値を管理し、`src/game/` はモンスター・火の玉攻撃・スコア計算を管理します。
- `src/input/` はカメラとモーション検出、`src/audio/` は効果音とBGMを管理します。
- `src/game/runtime.js` はゲーム進行と画面表示をまとめています。
- `src/view.html` と `src/styles.css` は画面テンプレートとスタイルです。
- `src/game/boss.js` は最後の5秒に出るボスの移動と体力を管理します。
- `src/game/ghost.js` は前のプレイヤーの記録の圧縮・補間を担当します。
- `src/game/coop.js` は「ふたりで きょうりょく」の手の選び方と、合体技を出すかどうかの判定です。
- `assets/` に背景透過の `slime.png`、`ghost.png`、`bat.png`、`golem.png`、`star.png`、`bomb.png`、`fireball.png`、`boss.png` を置くと、対応する絵に差し替わります。

## BGM

`assets/` に `bg.mp3`（`bgm.mp3`、`.ogg`・`.m4a`・`.wav` でも可）を置くと、プレイ中にくりかえし流れます。ファイルがないときは、プログラムで作った曲が流れます。音量は `TUNING.bgmVolume`、ラスト10びょうの速さは `TUNING.bgmLastRate` で調整できます。

## ジェスチャー必殺技

敵をたおすと画面右下の「必殺」ゲージがたまります。満タンのときに手の形を見せて、0.4びょう手を止めると必殺技が出ます（動かしている間は出ないので、斬っている最中に暴発しません）。

| 手の形 | 技 | こうか |
|---|---|---|
| ✋ パー | しょうげきは | 手のまわりの敵をまとめてたおす。ばくだんは安全に消え、火の玉ははじき返す |
| ✌ ピース | バリア | 6びょう間、火の玉を自動ではじき、ばくだんにさわっても時間がへらない |
| ✊ グー | ゲンコツ | ボスに60ダメージ。ボスがいないときは、画面じゅうの敵に1ダメージ |

手の形は、手首から指先までの長さと、手首から第2関節までの長さをくらべて見分けています（`src/input/gesture.js`）。「AIの目」をONにすると、見分けた形が手の下に出ます。マウス・モーションのときは、キーボードの `1`・`2`・`3` で出せます。数値は `TUNING.special` で調整できます。

## けっか画面で次のモードをえらぶ

けっか画面で、次のプレイの「むずかしさ」「そうさ（AIハンド・モーション・マウス）」「人数（ひとり・ふたり）」をえらべます。そうさを変えたときは、カメラとAIの準備からやり直します。

## ふたりで きょうりょく

メニューの PLAYERS で「ふたりで きょうりょく」を選ぶか、URLに `?coop=1` を付けると、2人で1つのスコアをめざして遊べます。

- カメラの前に2人でならび、**1人1本ずつ** 人さし指を使います。画面の左に立った人が水色、右に立った人がピンクのゆびになります（左右それぞれで、いちばん大きく写った手を使います）。
- AIハンドのときは、2つの手がそろうとスタートします（1つだけのときは「あと ひとり、手をかざしてね！」）。
- 敵が多めに出て、ボスはHPが1.6倍になるかわりに、のこり8びょうで早めに出ます。必殺ゲージは18体で満タンです。
- **合体技**: 必殺ゲージが満タンのとき、2人が同時に同じ手の形をして止めると、手と手がいなずまでつながり、合体技が出ます。1人だけが形を作っているときは「あいぼうも ✊！」と出て1びょう待ち、あいぼうが間に合わなければ、ふつうの技が出ます。

| 手の形 | 合体技 | こうか |
|---|---|---|
| ✋✋ パー | ダブルしょうげきは | 2人の手から大きなしょうげきは ＋ 2人の手をむすぶビーム。火の玉はぜんぶはじき返す |
| ✌✌ ピース | ダブルバリア | 10びょう間のバリア ＋ フィーバー（とくてん2ばい） |
| ✊✊ グー | ダブルゲンコツ | ボスに150ダメージ。ボスがいないときは、画面じゅうの敵をたおし、ばくだんも消す |

- けっか画面には、水色・ピンクがそれぞれ斬ってたおした数と、合体技の回数が出ます。ランクの基準点は1.5倍です。
- ランキングとゴーストは「ひとり」と「ふたり」で別々です（ふたりの記録は「ペア1」などの名前になり、「本日の挑戦者」は2人と数えます）。
- マウス・モーションのときは、`Shift` をおしながら `1`・`2`・`3` で合体技を出せます（スタッフ・確認用）。

数値は `src/config.js` の `TUNING.coop` で調整できます。

## 激ムズモード

メニューの LEVEL で「☠ 激ムズ」を選ぶか、URLに `?diff=extreme` を付けると遊べます。

- 敵が速く・多くなり、当たり判定がせまくなります。
- ばくだんが「むずかしい」の約2倍出て、同時に最大4こ出ます。
- 火の玉は1.3〜2.2びょうごとに、2こずつ飛んできます（同時に最大4こ）。
- **逆転ゲージ**: ばくだんか火の玉に3回当たると「逆転タイム」になります。6びょう間、得点が2倍になり、時間が3びょうもどります。ばくだんは金色に変わり、さわると爆発して、まわりの敵をまとめてたおせます。

- 敵や火の玉が多くて画面が見えにくくならないよう、うかぶ文字を少なくしています。「OUCH!」「BOMB!」「GOOD!」などの大きな文字や、+10 などの小さな数字は出さず、50点以上の数字と、ボス・逆転タイム・必殺技の知らせだけを出します。火の玉のヒビもすぐ消えます。

数値は `src/config.js` の `TUNING.difficulty.extreme`・`TUNING.attacks`・`TUNING.comeback`・`TUNING.quietUi` で調整できます。

## ボス戦

残り5秒になるとスライムキングが登場します。速い斬りで体力を削りきると500点のボーナスを獲得できます。ボスがいる間、火の玉は出ず、通常モンスターは最大6体です。倒せなかった場合は結果画面に残りHPが表示されます。スタッフメニューでオン・オフでき、URLに `?boss=0` を付けても無効にできます（既定はオン）。

## ゴーストレース

プレイ中は両手の座標と得点だけを0.1秒ごとに保存し、次のプレイヤーに水色の残像と比較得点を表示します。プレイ後は前の記録を置き換えます。名前・顔・映像は保存しません。「今日の記録をリセット」でゴーストも消えます。スタッフメニューまたは `?ghost=0` で無効にできます（既定はオン）。長時間プレイの記録は保存サイズの上限内に収まるよう間引かれます。

## URL オプション

- `?booth=1` ブース表示
- `?mode=ai`、`?mode=motion`、`?mode=mouse` 操作モード
- `?diff=easy`、`?diff=normal`、`?diff=hard` 難易度
- `?time=30` プレイ時間（10〜180秒）
- `?view=show`、`?view=blur`、`?view=hide` カメラ映像の表示方法
- `?mute=1` 消音、`?assets=0` 画像を無効化、`?attack=0` 火の玉攻撃を無効化
- `?boss=0` ボス戦を無効化
- `?ghost=0` ゴーストレースを無効化
- `?coop=1` ふたりで きょうりょく
