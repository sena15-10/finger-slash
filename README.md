# FINGER SLASH

カメラとAIで遊ぶアクションゲームです。カメラ映像はブラウザー内で処理し、録画・送信しません。

## 開発

Node.js をインストールしてから、プロジェクトのフォルダーで実行します。

```sh
npm install
npm run dev
```

本番用ファイルは次のコマンドで `dist/` に作成されます。

```sh
npm run build
npm run preview
npm test
```

Netlify Drop などへ公開するときは、`dist/` の中身をアップロードしてください。カメラを使う場合は HTTPS で開きます。

## ファイル構成

- `index.html` はアプリの起動に必要な最小のHTMLです。
- `src/main.js` はスタイルと画面テンプレートを読み込み、ゲームを起動します。
- `src/config.js` はゲームの調整値を管理し、`src/game/` はモンスター・火の玉攻撃・スコア計算を管理します。
- `src/input/` はカメラとモーション検出、`src/audio/` は効果音とBGMを管理します。
- `src/game/runtime.js` はゲーム進行と画面表示をまとめています。
- `src/view.html` と `src/styles.css` は画面テンプレートとスタイルです。
- `src/game/boss.js` はボス（スライムキング）の移動・火の玉の発射タイミング・体力を管理します。
- `src/game/ghost.js` は前のプレイヤーの記録の保存・補間を担当します。
- `src/game/gesture.js` は手の形（グー・パー）の判定と、こぶしゲージ・盾の状態を管理します。
- `assets/` に背景透過の `slime.png`、`ghost.png`、`bat.png`、`golem.png`、`star.png`、`bomb.png`、`fireball.png`、`boss.png` を置くと、対応する絵に差し替わります。

## ボス戦

プレイ時間が30秒なら残り5秒、60秒なら残り15秒になるとスライムキングが登場します（体力は30秒版150・60秒版300）。画面の上のほうを左右にゆっくり往復し、出現から3秒後・その後3秒ごとに火の玉を投げます（投げる0.6秒前に光って「！」を出します）。同時に2発を超える火の玉は投げません。

通常の斬り（220px/秒以上）は0.12秒おきに10点ぶんのダメージ、火の玉を斬ってはじき返してボスに当てると30点ぶんのダメージになります。体力を削りきると「ボスをたおした！」で500点（コンボ倍率なし）が入り、ボス・火の玉が消えます。倒せなかった場合は結果画面に「ボスのHP 残り◯%」が表示されます（切り上げ。1%未満でも0%にはなりません）。

ボスがいる間、通常モンスターは最大6体、通常の火の玉攻撃は出ません（ボス自身の火の玉だけが出ます）。スタッフメニューでオン・オフでき、URLに `?boss=0` を付けても無効にできます（既定はオン）。

## ゴーストレース

プレイ中は、斬りに使っている点（指先。マウスはカーソル）の座標（0〜1に正規化）と得点を0.1秒ごとに記録し、時間切れで終わったときだけ30秒用・60秒用それぞれ別の記録として保存します（途中でメニューに戻ったときや、手が一度も映らなかったときは保存しません）。次のプレイヤーには、同じ時間モードの前の記録を水色の残像と「前の人 ◯点／いま ◯点」の比較バーで表示し、結果画面に「前の人をこえた！」などの文言を出します。保存するのは座標と得点だけで、名前・顔・映像は保存しません。「今日の記録をリセット」で両方の記録が消えます。スタッフメニューまたは `?ghost=0` で無効にできます（既定はオン、既存の記録は消えません）。

## 手の技（グー・パー）

指（人さし指・中指・薬指・小指）が3本以上曲がっていると「グー」、4本とも伸びていると「パー」と判定します。こぶしゲージは、通常の敵を1体たおすごとに10%、ボスへ斬りダメージが1回入るごとに2%たまり、100%の状態でグーを0.5秒続けると発動して、画面の通常モンスターを全滅・ボスに30ダメージ・飛んでいる火の玉をすべて消します（発動後、ゲージは0に戻ります）。パーを0.3秒続けると2秒間、手のひらに追従する盾が出て、触れた火の玉を消します（再使用まで8秒）。グーの形を作っている間は、その手の斬り判定の位置が更新されません（誤って斬らないため）。

マウス操作のときは、右クリック長押しがグー、Shiftキー長押しがパーの代わりになります（右クリックのメニューは出ません）。スタッフメニューまたは `?gesture=0` で、ゲージ・判定・表示・マウスの代わりをすべて無効にできます（既定はオン）。

## URL オプション

- `?booth=1` ブース表示
- `?mode=ai`、`?mode=motion`、`?mode=mouse` 操作モード
- `?diff=easy`、`?diff=normal`、`?diff=hard` 難易度
- `?time=30` または `?time=60` プレイ時間（それ以外の値は無視され、既定は30秒）
- `?view=show`、`?view=blur`、`?view=hide` カメラ映像の表示方法
- `?mute=1` 消音、`?assets=0` 画像を無効化、`?attack=0` 火の玉攻撃を無効化
- `?boss=0` ボス戦を無効化
- `?ghost=0` ゴーストレースを無効化
- `?gesture=0` 手の技（グー・パー）を無効化
