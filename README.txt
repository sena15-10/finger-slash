FINGER SLASH（フィンガースラッシュ）
カメラ × AI で遊ぶアクションゲーム ／ ブース体験用

────────────────────────────
■ 中身
────────────────────────────
  index.html … ゲーム本体（このファイル1つで動きます）
  README.txt … この説明書
  assets/    … （任意）モンスターを画像にしたいときに作るフォルダ

────────────────────────────
■ 公開のしかた（Netlify Drop）
────────────────────────────
  1. このフォルダ（finger-slash）を用意する
  2. Chrome で https://app.netlify.com/drop を開く
  3. フォルダをページにドラッグ＆ドロップ
     → 数秒で「○○○.netlify.app」というURLが発行されます
  4. 無料アカウントを作って、サイトを自分のものにする
     （アカウントなしのサイトは、短時間で消えます）
  ※ カメラは「https://」で始まるURLでないと使えません（Netlify は自動で https）

────────────────────────────
■ 画面の流れ（ブース展示モード）
────────────────────────────
  待機画面（タイトル・本日のランキングTOP10・あそびかた・モンスター紹介が切りかわる）
    ↓ 手をカメラに約1びょうかざす（輪のメーターがたまる）
  READY? → 3 → 2 → 1 → START!
    ↓ 30びょうプレイ（BGMあり。ラスト10びょうで警告）
  FINISH!
    ↓
  リザルト（スコア → 記録 → ランクのスタンプ → 本日の順位 の順に出る）
    ↓ 12びょう後に自動で（または「つぎの人へ」ボタン）
  待機画面「NEXT PLAYER! つぎの人、どうぞ！」（2.5びょうは反応しない）

  プレイ中の演出
    ・5／10／20／30／50コンボで GOOD! GREAT! EXCELLENT! AMAZING! LEGEND!
    ・ほしをとると FEVER TIME!!（8びょう間 得点2倍、BGMも変わる）
    ・ばくだんにさわると BOMB!（−3びょう）
    ・ゴーレムをたおすと、一瞬止まる「ヒットストップ」

────────────────────────────
■ てきの攻撃（火の玉）
────────────────────────────
  スタッフメニューの「てきの攻撃」で あり／なし を切りかえられます（はじめは「あり」）。
    1. 開始6びょう後から、画面の敵の頭の上に「！」が出て、火をためる（0.6びょう）
    2. 火の玉が、だんだん大きくなりながら飛んでくる。当たる場所には赤い照準が出る
    3. 大きくなりきる前に剣（人さし指）で斬ると「はじいた！」＋30点（コンボ倍率がかかる）
    4. 斬れずに当たると、画面にヒビが入って「OUCH!」 −2びょう、コンボも0にもどる
    ・「！」が出ている間に、その敵をたおせば、攻撃は消える
    ・同時に飛んでくるのは2つまで。むずかしさで速さと間かくが変わる
        やさしい … 2.2びょうで届く／5〜7びょうごと
        ふつう   … 1.8びょうで届く／3.5〜5.5びょうごと
        むずかしい … 1.4びょうで届く／2.5〜4びょうごと
    ・結果画面に「はじいた火の玉」の数が出る（攻撃なしのときは出ない）
    ・その場から動かずに遊べるので、座ったままでもOK
    ・届くまでの時間・当たったときに減る時間などは、index.html の TUNING の attacks で変えられます

────────────────────────────
■ 開場前のじゅんび（15分）
────────────────────────────
  1. 公開したURLを開く（おすすめ: 末尾に ?booth=1 を付ける）
  2. メニュー右下の「STAFF」で
       使い方 … ブース展示
       えいぞう … そのまま／ぼかし／かくす
  3. モード「AIハンド」、TIME「30」で「GAME START」をおす
     → 全画面になり、カメラの許可を聞かれたら「許可」
  4. AIの読み込みを待つ（初回 10〜40びょう。約22MB）
  5. スタッフが立ち位置に立って、1回テストプレイ
  6. 「S」キーでメニューにもどり、「今日の記録をリセット」を2回おす
  7. もう一度「GAME START」をおして、待機画面のまま開場

  ★ AIを読み込んだあとは、ページを再読み込みしないでください。

────────────────────────────
■ 来場者が多いとき（200人以上）
────────────────────────────
  1人あたり 約1分（プレイ30びょう＋演出＋結果12びょう＋交代）
  → 1台で 1時間に 40〜50人が目安
  ・4時間以上あれば 1台でも200人に対応できる見込み
  ・時間が短いときは、TIME を「20」にするか、PC・カメラ・モニターを2セットにする
    （2台にしたときのランキングは、台ごとに別々になります）

────────────────────────────
■ モンスターを画像に差しかえる
────────────────────────────
  index.html と同じ場所に「assets」フォルダを作り、次の名前で画像を入れるだけです。
  入っていない分は、今までの絵のまま表示されます。

    assets/slime.png   … スライム
    assets/ghost.png   … ゴースト
    assets/bat.png     … コウモリ
    assets/golem.png   … ゴーレム
    assets/star.png    … ほし
    assets/bomb.png    … ばくだん
    assets/fireball.png … 火の玉（なくてもOK）

  画像のルール
    ・PNG形式で、背景は透明
    ・正方形（512×512 くらい）、キャラクターを真ん中に大きく
    ・1枚に1体だけ。文字は入れない
    ・太めのふちどりがあると、カメラ映像の上でも見やすい
  ※ 動き（ぷるぷる・羽ばたき・回転など）はプログラムがつけます
  ※ ばくだんの赤い点線の輪と、ゴーレムの体力（●●●）は画像の上に自動で表示されます
  ※ 大きさを変えたいときは index.html の MON の「spr」の数字を変える

────────────────────────────
■ スタッフ用のキー
────────────────────────────
  S … メニューへもどる（プレイ中は、まず一時停止）
  P … 一時停止／再開
  N … リザルトから、すぐ次の人へ
  F … 全画面の切りかえ
  M … 音のON／OFF
  E … 「AIの目」（手の21点）をプレイ中も表示
  タッチ画面だけのときは、画面の左上を1.5びょう長おしでメニューへ

────────────────────────────
■ 映像のあつかい
────────────────────────────
    そのまま … 自分が写るので一番もりあがる。うしろに人が写りやすい
    ぼかし   … 動きはわかるが、顔はわからない
    かくす   … 映像は出さず、手の点と剣の光だけを表示
  ・カメラの映像は、録画も送信もしません（PCの中だけで処理）
  ・ブースに「カメラを使っています／録画・保存はしません」と掲示してください

────────────────────────────
■ うまく動かないとき
────────────────────────────
  ・手を見つけない … 窓や照明を背にしていないか。手のひらをカメラに向ける
  ・手と剣（点）が ずれる … 検出の遅れを先読みで打ち消しています。それでも気になるときは
                     index.html の TUNING の ai を調整:
                       点が手より「遅れる」  → pipelineMs を大きく（40 → 70 など）
                       点が手より「行きすぎる」→ pipelineMs を小さく（40 → 15 など）
                       止めたときに ぷるぷるする → smoothMin を小さく（0.35 → 0.25）
  ・反応がカクカク … AIは起動時にGPU方式とCPU方式の速さを測り、速いほうを自動で使います。
                     それでも極端に重いPCでは、自動でモーションモードに切りかわります
  ・AIが読み込めない … 会場のネットを確認。自動でモーションに切りかわります
  ・カメラが外れた … つなぎ直して、S → 「GAME START」
  ・BGMを止めたい … index.html の TUNING の music を false に

────────────────────────────
■ URLオプション
────────────────────────────
  ?booth=1        … ブース展示（0 で ふつう）
  ?mode=ai        … AIハンド（motion / mouse も可）
  ?diff=easy      … むずかしさ（easy / normal / hard）
  ?time=30        … 1回の時間（びょう）
  ?view=blur      … 映像（show / blur / hide）
  ?mute=1         … 音なし
  ?assets=0       … assets フォルダの画像を使わない
  ?attack=0       … てきの攻撃なし（1 で あり）
  ?delegate=cpu   … AIをCPU方式に固定（gpu でGPU方式に固定。ふつうは付けない）
  例: https://○○○.netlify.app/?booth=1&mode=ai&time=30&view=blur
